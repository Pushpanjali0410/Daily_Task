
# 🚀 RAG Pipeline with FAISS and Groq Integration

A powerful **Retrieval-Augmented Generation (RAG)** system that combines local **FAISS vector database** with **Groq API** for intelligent, cost-free question-answering across multiple domains.

## ✨ Features

### 🎯 **Multi-Domain Support**
- **What were the document uploaded by user. for example following pdf/text files:**
- 📋 **Intellectual Property** documents
- 🧠 **Machine Learning** research & papers
- ☀️ **Solar Technology** specifications
- 🏥 **Medical Electronics** documentation
- ➕ **Any other domain** you upload

### 🔍 **Intelligent Retrieval**
- Semantic search (understands meaning, not just keywords)
- FAISS vector database (free, local, fast)
- Document ranking by relevance
- Configurable top-K retrieval

### 💬 **Advanced Generation**
- Groq API for ultra-fast inference
- Multi-turn conversations with memory
- Context-aware responses
- Multiple model support

### 💰 **Cost-Effective**
- ✅ FAISS - completely free (local)
- ✅ Groq API - free tier available
- ✅ No cloud storage costs
- ✅ No subscription required

---

## 📋 Prerequisites

- **Python 3.8+**
- **Windows/Mac/Linux**
- **Internet** (for Groq API)
- **Groq API Key** (free from https://console.groq.com)
