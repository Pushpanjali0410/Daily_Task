# 🎯 Clickbait Detection System

## What is Clickbait?

**Clickbait** is a sensationalized headline designed to trick users into clicking a link. Examples include:
- "You won't believe what happened next..."
- "Doctors hate this simple trick..."
- "This one weird tip will change your life..."

This project uses **Machine Learning** to automatically detect such headlines.

## 🚀 Features

- **No external data needed** - Built-in dataset of 30+ headlines
- **Multiple detection methods** - TF-IDF + custom clickbait features
- **Interactive testing** - Test your own headlines
- **Confidence scores** - See how sure the AI is
- **Detailed explanations** - Why a headline is clickbait
